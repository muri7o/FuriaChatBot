# FuriaChatBot

Chatbot multilíngue desenvolvido para o processo seletivo de estágio da FURIA. O projeto utiliza HTML, CSS e JavaScript para criar uma interface interativa e responsiva.

## 🌐 Demonstração

Acesse a versão online do projeto aqui: [muri7o.github.io/FuriaChatBot](https://muri7o.github.io/FuriaChatBot)

## 📁 Estrutura do Projeto

- **index.html**: Página principal do chatbot em português.
- **index-en.html**: Versão em inglês.
- **index-es.html**: Versão em espanhol.
- **style.css**: Estilos e layout responsivo.
- **script.js**: Lógica de interação do chatbot.
- **img/**: Imagens utilizadas na interface.

## 🧠 Funcionalidades

- Interface amigável e responsiva.
- Suporte a múltiplos idiomas (Português, Inglês e Espanhol).
- Respostas automatizadas simulando um atendimento básico.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
